# eyewear_tryon_ios

The iOS implementation of [`eyewear_tryon`](https://pub.dev/packages/eyewear_tryon).

> **Preview.** This version registers the platform view and channels but shows a placeholder instead of the camera try-on. The ARKit + SceneKit renderer is in progress.

## Usage

This package is [endorsed](https://flutter.dev/to/endorsed-federated-plugin): add `eyewear_tryon` to your app and it is included automatically on iOS. When the camera renderer ships, apps will need `NSCameraUsageDescription` in Info.plist.
