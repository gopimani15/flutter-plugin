# eyewear_tryon_android

The Android implementation of [`eyewear_tryon`](https://pub.dev/packages/eyewear_tryon).

> **Preview.** This version registers the platform view and channels but shows a placeholder instead of the camera try-on. The CameraX + MediaPipe + Filament renderer is in progress.

## Usage

This package is [endorsed](https://flutter.dev/to/endorsed-federated-plugin): add `eyewear_tryon` to your app and it is included automatically on Android.
